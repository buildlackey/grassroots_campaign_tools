# Generic Build Framework for Google Sheets Extensions


## Overview

This repository provides an end-to-end, opinionated build system and utility libraries 
for Google Sheets Add-ons that use Google's paid Web APIs.  

Initially, we will only support the Maps API, so for historical reasons you will often see 
code artifacts with 'Maps' in their names.

Please consult the [project documentation](doc/OVERVIEW.md) for details.



## Pre-requisites
- Node.js
- Google Cloud CLI 
- Google oauth-client
