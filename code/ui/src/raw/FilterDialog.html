How This Works

This HTML page references an external SVG file (icon.svg) and displays it inline with header text, with the icon sized to be 25% larger than the 24px font height.

The key elements:

  • The .icon-container div has fixed dimensions of 30x30px (25% larger than 24px)
  • The img element inside references the external SVG file
  • The SVG is scaled with height: 100%; width: 100%; object-fit: contain;
  • Flexbox layout aligns the icon and text properly
  • Content text is set to 10px font size as requested

File Information: The HTML file references the SVG file with <img src="icon.svg" alt="Header Icon">. Both files need to be in the same directory for this to work.
Note: To use your own SVG, simply replace the icon.svg file with your SVG file (using the same filename), or update the src attribute in the img tag to point to your SVG file.
